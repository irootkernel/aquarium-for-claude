# Changelog

This file records concise shipped outcomes of the Aquarium for Claude edition. Releases before v0.1.14 are recorded in this repository's Git tags and GitHub releases; upstream outcomes live in the [Aquarium changelog](https://github.com/irootkernel/aquarium/blob/main/CHANGELOG.md).

## v0.1.21 - Unreleased

### Added

- Run Herdr Review on this host. Upstream v0.1.19 replaced Orca Review and the `orca-review` entry point with `herdr-review`, which supervises one fresh explicitly requested reviewer in the current local Herdr session for a staged, `HEAD`, commit, or range target and is model-invocable under upstream's sidecar. Its upstream `herdr` skill is expected under the configured Claude Code skill root, where Claude Code loads it by its slash name, so `$herdr` becomes `/herdr` behind a new rule and forbidden needle while the `$orca-cli` rule and needle retire with Orca; the catalog requires Herdr client and server v0.9.3 or newer, `HERDR_ENV=1`, and that skill; the route's cross-family preference reads "Prefer a reviewer kind outside the Coordinator's AI family." instead of naming both hosts; and the qualification sentence asks for observations per reviewer agent kind. `/aquarium:orca-review` is gone.
- Ship upstream's adaptive-procedure helpers and keep their digest-pinned data verbatim. v0.1.20 added the plugin-root `shared/` helpers that every Podway-backed workflow and the repository inspector load, and adaptive data whose `known-sources-v2.json` pins the SHA-256 of every bundled Procedure while its capability signatures and operation contracts pin canonical JSON. `shared/` joins `COPIED_DIRECTORIES`, `assets/adaptive/` and `assets/schemas/` become `VERBATIM_DIRECTORIES` that every scan reads and no rule rewrites, and `tests/validate.rb` asserts all three trees byte-identical to upstream and pins the names `shared/` imports from `inspect_tools.py` and `goal-evaluator`'s `ordinary_assignment.py`. The helpers need PyYAML and `jsonschema`, which upstream does not install either; without them the selected-Procedure inspection fails closed with `missing-prerequisite`, and a new unit test covers both missing imports.
- Dispatch ordinary-orchestration roles as Opus subagents that read their skills by path. v0.1.20 has a workflow Coordinator run its Executors and Evaluator as native subagents of its own harness on harness defaults; here they are Claude Code subagents that request `opus` unless the user names another model, so Fable runs only on explicit request, and each assignment carries the owning Aquarium skill's `SKILL.md` absolute path — also for Procedure node text such as `Use task-implement`, which is byte-canonical YAML — because a subagent cannot load a gated skill through the Skill tool. The Evaluator receives `goal-evaluator`'s path and each Executor that of the executor guidance, and the retained v2 contract's Primary, Worker, and Judge get the same rule. The agent and task orchestration references the handlers read before dispatching state the same baseline and point at that contract.

The catalog ports the disclosed release, tag, and commit lookup boundary, the Complete Paired-Skill Inventory, the pinned skill installer with `--agent claude-code`, Sanho v0.2.9 with `sync --inspect`, the Dolgorae skill inventory, the Herdr section, Mulgae v0.1.25 with Config v5, its `start_review`, `await_review`, and `inspect_review` tools, and no `.mulgaeignore` processing, Gaori v0.1.18, Sorage v0.1.2 with Project Memos and the format-1 backup and restore preflight, and Podway v0.2.14 or newer with the Direct CLI, observation v5, and the adaptive launcher; it drops the 3601-second Gaori host deadline this edition carried over from upstream's old `tool_timeout_sec` floor, because v0.1.18 replaced that floor with a rule never to impose one, and keeps the development-channel and production-status sections and the other host's skill homes out. `dev-setup-global` ports the commit-attribution line, the adaptive-launcher prerequisite paragraph, `required_global_mcp`, Podway's Direct CLI identity, and the pre-Memo Sorage preparation. Five new reviewed `Codex` exemptions cover the references and the mapper that describe the other host's record formats or its dormant formal-delegation binders, six in all.

### Fixed

- Stop workflows from halting when they hand a step to a gated skill. Upstream skills delegate by name — `task-handler` loads its seven phase skills, `release-handler` runs `release-qa`, and `dev-setup-bundle` prepares global components through `dev-setup-global` — which Codex treats as an explicit invocation, but Claude Code's Skill tool refuses a `disable-model-invocation` skill unless the user typed its name in the current turn, always refuses it inside a subagent, and forbids carrying out the refused workflow by other means, so the model stopped at every such hand-off. Generation now opens every gated upstream-derived skill, overrides included, with a note directly under its title that has Claude read the delegated skill's `SKILL.md` and follow it instead of calling the Skill tool, give that file's absolute path to any subagent it hands the step to, and keep returning a continuation request the text hands back to the user instead of running it; model-invocable skills carry no note, so a hand-off from a skill Claude started on its own still goes back to the user, a skill body that does not open with its title stops generation, and `tests/validate.rb` asserts the note in every gated upstream-derived skill, exactly once under its title, and its absence everywhere else.
